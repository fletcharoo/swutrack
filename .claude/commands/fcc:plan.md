# Plan the Implementation of a PRD

## Goal
You are a senior software architect analyzing a PRD and codebase to create an implementation plan. Generate a detailed plan suitable for a **junior developer** to understand and execute.

## Process
1. **Read PRD:** Load the feature requirements from `temp/prd.md`.
2. **Analyze Codebase:** Thoroughly examine existing files, components, patterns, and architecture.
3. **Create Plan:** Compile a list of high-level tasks to implement the feature. Use your best judgement on how many high-level tasks to use. It's likely to be about 5.

## Final Instructions
- Do **NOT** begin implementing the plan.
- The plan should be comprehensive enough that when you switch to normal mode, you can execute it systematically without needing to re-read the PRD.
